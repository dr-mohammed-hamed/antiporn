# 📚 بوابة التوثيق الهندسي والمعماري لمشروع «حِصْن» (Hisn Documentation Hub)

مرحباً بك في مركز التوثيق الموحد لمشروع **«حِصْن» (AntiPorn DO)**.  
يحتوي هذا المجلد على كافة الأدلة المعمارية، والرؤى الاستراتيجية، والدراسات التشريحية لنظام أندرويد لتمكين المطورين والمهندسين من فهم وتطوير والتوسع في منظومة الحماية.

### 🚀 روابط سريعة للمطورين:
* **هل تريد إضافة أو استثناء تطبيق جديد في القوائم البيضاء أو السوداء؟**  
  افتح [`AppPolicyRegistry.kt`](../app/src/main/java/com/drmohammed/antiporn/core/policy/AppPolicyRegistry.kt) وأضف سطراً واحداً في المصفوفة. راجع [دليل المطور](APP_POLICY_REGISTRY.md#7-دليل-المطور-لإضافة-وتعديل-التطبيقات-developer-how-to-guide) لمزيد من التفاصيل.
* **هل تبحث عن تعليمات التثبيت لأول مرة على هاتفك؟**  
  راجع [دليل البدء السريع في ملف الواجهة الرئيسي](../README.md#⚡-التثبيت-والتهيئة-لأول-مرة-عبر-adb-initial-setup).
* **هل ترغب في المساهمة البرمجية؟**  
  راجع [دليل المساهمة](../CONTRIBUTING.md) و [سياسة الأمان](../SECURITY.md).
